ติดตั้งบน iPhone / iPad (Safari)

  1. เปิดหน้านี้ด้วย Safari (ถ้าเปิดจาก Chrome ให้เปลี่ยนมา Safari ก่อน)
  2. แตะปุ่มแชร์ 􀈂 ที่แถบล่าง
  3. เลื่อนลงแล้วเลือก เพิ่มไปยังหน้าจอโฮม / Add to Home Screen
  4. แตะ เพิ่ม — จะได้ไอคอน CNC Tools ที่หน้าโฮม เปิดแล้วเต็มจอไม่มีแถบเบราว์เซอร์
